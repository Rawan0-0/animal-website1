Push your branch to GitHub 8. Create a pull request asking to merge your branch to `main` ### Part 3 - Merging 1. At this point your partner should have created a pull request. Merge the changes into your `main` branch. 2. **If you see a message about merge conflicts stop here**. That means something has gone wrong somewhere in this process. Post a message in Slack to ask for help. 3. You can **pull** the changes to your laptop to see what's different in the website. Click the three dots next to teh repository name in the source control tab and click "pull". If you see your partner's changes in your browser then everything has worked, well done! If not then you can post in Slack and ask for help, or speak to a volunteer in class. You should definitely speak to your partner and make sure nobody missed anything while working through the exercise.
